# 蔚来 2026 年二季度营业利润复盘

二季度集团交付比一季度多 24,193 辆，车辆业务毛利增加 10.92 亿元。同期研发与销管费用合计增加 11.87 亿元，其他业务毛利减少 0.45 亿元。计入其他经营收益后，营业亏损从 3.09 亿元扩大到 3.47 亿元。以下比较使用集团合并、单季、美国会计准则口径。[二季度公告，第 2、15 页](../data/raw/financials/2026Q2.pdf)

## 如何理解这笔变化

**交付与车辆毛利。** 交付从 83,465 辆增至 107,658 辆。按两季平均单车毛利衡量，数量变化对应约 +1,227.05 百万元。按两季平均交付量衡量，单车收入代理和单车成本代理的变化分别贡献约 −292.49 和 +157.47 百万元。三个数字合计对应表中的车辆毛利增量，展示值经过四舍五入。公司在季报中将车辆销售收入环比增加主要归因于交付增长。[二季度公告，第 2、5、15 页](../data/raw/financials/2026Q2.pdf)

**公司对费用的解释。** 公司将研发费用环比增长主要归因于新产品和技术的设计开发成本、研发人员成本上升。销管费用增长涉及新品上市营销、营销人员及相关成本，以及一般公司职能的股权激励费用。公告披露了成本类别，未列出各项对环比增量的具体贡献额。[二季度公告，第 6 页「Operating Expenses」](../data/raw/financials/2026Q2.pdf)

**仍待检验的假设。** 集中上市活动可能使本季销管费用偏高，人员及相关成本也可能在后续季度延续。下一次财报公布后，先比较交付、销管费用绝对额和环比变化，再核对新品推广节奏及股权激励披露。区分一次性活动与经常性支出，还需要活动分摊、成本确认月份和人员成本明细。

**单车代理值的边界。** 会计收入与交付量来自两套记录。2025 年报说明，车辆销售收入在产品控制权转移时确认，一份合同还可能包含按相对独立售价分摊的多项履约义务。车辆收入除以同期交付量可以描述单位交付对应的车辆会计收入。分析车型成交价和折扣需要合同或订单明细。[2025 Form 20-F，财务附注「Revenue recognition — Vehicle sales」](https://www.sec.gov/Archives/edgar/data/1736541/000110465926041765/nio-20251231x20f.htm)

## 从原始记录复算

在项目根目录运行以下命令。程序使用各季度自身公告，读取人民币元后换算到百万元，并检查会计残差。

```sh
python - <<'PY'
import csv
from decimal import Decimal
from pathlib import Path

with Path("data/quarterly.csv").open(encoding="utf-8") as f:
    rows = list(csv.DictReader(f))
def quarter(period):
    return {r["metric"]: Decimal(r["value"]) / 1_000_000 for r in rows
            if r["period"] == period and r["source_id"] == f"HKEX-FIN-{period}"}
a, b = quarter("2026Q1"), quarter("2026Q2")
def delta(metric):
    return b[metric] - a[metric]
effects = [delta("Rv") - delta("Cv"), delta("Ro") - delta("Co"),
           -delta("RD"), -delta("SG"), delta("OI")]
assert sum(effects) == delta("OP") == Decimal("-38.408")
print(*effects, "合计", sum(effects))
PY
```
